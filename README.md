# Event Cinema

Сайт персональных AI-роликов для мероприятий. Статика под GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий `ai-video-shop`.
2. Загрузите все файлы из этой папки (кроме `_slides`).
3. Settings → Pages → Deploy from a branch → `main` / корневая папка.
Сайт: https://stasshmatd-lang.github.io/ai-video-shop/

## Заявки

В `script.js` укажите Telegram без `@`:

```js
telegram: "username",
```

или WhatsApp в международном формате:

```js
whatsapp: "77001234567",
```

## Локальный просмотр

Откройте `index.html` в браузере или поднимите любой статический сервер в этой папке.
